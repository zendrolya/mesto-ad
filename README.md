# Mesto

Mesto — интерактивный веб-проект, в котором пользователи могут редактировать профиль, обновлять аватар, добавлять новые карточки с изображениями, ставить лайки, удалять собственные карточки и просматривать информацию о карточках.

## Функциональность проекта

- Редактирование имени и описания профиля
- Обновление аватара пользователя
- Добавление новых карточек
- Удаление собственных карточек с подтверждением
- Лайки карточек
- Просмотр изображений в полноразмерном формате
- Просмотр информации (ветка mesto-report) и статистики карточек
- Валидация всех форм
- Работа с API-сервером
- Автоматический деплой на GitHub Pages через GitHub Actions

## Технологии

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Vite
- GitHub Actions
- GitHub Pages

## Установка и запуск проекта

### Запуск локального сервера разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

### Публикация проекта

```bash
npm run deploy
```
